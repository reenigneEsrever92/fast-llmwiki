# Backlog

The backlog holds proposed and planned changes. Each item is a
`type: ChangeRequest` document with a `state` that moves through
`proposed` → `planned` → `in-progress` → `done` (or `rejected` / `superseded`
when it no longer applies).

- [Full-text search](full-text-search.md)
- [Surface dev fields in the web UI](surface-dev-fields.md)
- [Relevance-ranked search results](relevance-ranked-search.md)

See [Development](../index.md) for the workflow and the `fawi-propose`,
`fawi-plan`, `fawi-implement`, and `fawi-check` skills.
